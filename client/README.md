# Client (Frontend)

Overview

The `client` folder contains the frontend application for RideFlow — the user-facing interface for browsing vehicles, making bookings, and managing customer accounts.

Getting Started (example)

1. Install dependencies: `npm install`
2. Create `.env` with any required API base URL and keys.
3. Run dev server: `npm run dev`
4. Build for production: `npm run build`

Key Features

- Vehicle browsing, filtering and comparison
- Booking flow with calendar integration
- Customer dashboard for reservations and status

Notes

Adjust commands and environment variables to match the chosen frontend framework (React/Vue/Svelte) and package manager.
